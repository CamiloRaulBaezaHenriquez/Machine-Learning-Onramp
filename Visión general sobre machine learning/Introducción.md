Visión general del curso y requisitos previos

Machine Learning Onramp ofrece una guía sobre el flujo de trabajo de machine learning, centrándose en la creación de modelos de clasificación.
Clasificación implica asignar una observación a una clase de un conjunto discreto de clases.
En lugar de crear un modelo manualmente, los algoritmos de machine learning crean modelos a partir de datos para asignar entradas a salidas.
En este curso, trabajará con un ejemplo manual para aprender el flujo de trabajo de clasificación: importar, extraer características, y crear y evaluar un modelo de predicción.

Este curso da por sentado que tiene conocimientos básicos de MATLAB®. Si desea ampliar sus conocimientos, complete el curso introductorio MATLAB Onramp para iniciarse rápidamente.
